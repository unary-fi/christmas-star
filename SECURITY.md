# Security policy

The Christmas Star pairs with phones over Bluetooth, unlocks its command line
with a challenge-response on a shared key, and only boots firmware signed
with the project's key. If you find a way around any of this, or another
security problem, please tell us privately first.

## Reporting

- Use GitHub's **Report a vulnerability** button on the repository's
  *Security* tab (private advisory), or
- email **info@unary.fi**.

Please include the firmware or app version and the steps to reproduce. We
will answer within a week and agree with you on a date for publishing.

## Supported versions

Only the newest release in
[christmas-star-releases](https://github.com/unary-fi/christmas-star-releases/releases)
gets security fixes; stars update over Bluetooth from the app.
