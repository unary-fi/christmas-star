# Christmas Star LED layout

> Generated by `sw/tools/gen_led_layout.py` from `hw/christmas-star/production/positions.csv`. Do not edit by hand.

## Structure

- 132 LEDs in **one data chain**: D201 → D266 (front face, PCB top layer), then D301 → D366 (back face, PCB bottom layer).
- Each face is a six-pointed star (hexagram) with a radius of 110 mm:
  - **Outline**: 48 LEDs, 8 per star point (concave vertex at r = 62.5 mm, then 74, 86, 100, tip at 110, 100, 86, 74 mm).
  - **Inner star**: 18 LEDs, rotated 30° to the outline. Its 6 tips sit at r = 50 mm and point at the outline's concave vertices; 12 LEDs at r ≈ 30 mm flank them.
- The back face LEDs sit at exactly the same XY as the front face LEDs (each LED has a *partner* on the other face).

## Addressing

| Term | Meaning |
|---|---|
| Side | 1 = front (top layer, D2xx), 2 = back (bottom layer, D3xx). Used by `set_led` / `set_all`. |
| Index | 1–66, the designator number: side 1 index 32 = D232. |
| Logical index | 0–131, position in the data chain (D201 = 0, D366 = 131). Used inside the firmware and in effect files. |

## Coordinates

- Front-view millimetres, origin at the star centre, x right, y up (as seen when looking at the front face).
- Polar angle: 0 = right, counter-clockwise, stored as 0–255 for 0–360°.
- Bitmap grid: 32×32 cells (≈7.1 mm per cell), row 0 at the top. Every LED has its own cell; there are no collisions.
- `point` 0–5 numbers the points clockwise: outline points start from the top point, inner-star tips start from the upper-left tip (120°). `step` is the position along the outline (0–47) or inner star (0–17), clockwise from the same start.

Effect files from `make_effect.py` sample images at these grid positions. Use the bitmaps below as a template when drawing a 32×32 image.
